Uma Regex, trata-se de uma representação de um padrão de cadeias de caracteres, de modo que podem ser utilizadas em diferentes contextos, para identificar padrões de dados, nos quais
um usuário irá preencher, exemplos:

r'[+-][0-9]': Representa valores inteiros de 0 até 9, positivos ou negativos

r'[a-zA-Z0-9_]': Representa caracteres alfanuméricos incluindo o underline

r'[a-z]': Representa caracteres minúsculas de a até z

r'[a-zA-Z]': Representa caracteres minúsculos e maiúsculos de a até z

*: zero ou mais repetições

+: uma ou mais repetições

?: nenhuma ou uma repetição

.: qualquer caractere

\: caractere especial

^: início de uma streing

$: fim de uma string
